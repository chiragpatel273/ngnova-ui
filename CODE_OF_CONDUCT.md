# Code of conduct

NgNova UI contributors and maintainers are expected to make project spaces respectful, inclusive,
and focused on constructive technical collaboration.

## Expected behavior

- Be considerate, patient, and specific.
- Critique ideas and code, not people.
- Welcome different experience levels, identities, abilities, and perspectives.
- Respect privacy and avoid publishing another person's personal information.
- Accept maintainer decisions gracefully while using the documented appeal or discussion path.

Harassment, threats, discrimination, sexualized conduct, deliberate intimidation, sustained
disruption, and retaliation are not acceptable.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile contact options.
Do not use a public issue when a report contains personal or sensitive information. Maintainers may
edit or remove content, lock discussions, reject contributions, or temporarily or permanently ban
participation when necessary.

Reports will be handled as confidentially as practical. Good-faith reports and participation in an
investigation must not result in retaliation.
